# 星铁四种挑战 Skia 模板素材来源

- 设计依据：本机 Miao-Yunzai 的 `plugins/genshin/resources/html/abyss/abyss-floor.html` 与 `abyss-floor.css`。
- `floor12.png`、`star.png`、`fonts/HYWenHei-55W.ttf`、`fonts/tttgbnumber.ttf`：来自同一 genshin 模块的 `resources/img/abyss` 和 `resources/font`，保留原文件。
- genshin 所属源码仓库：<https://gitee.com/yoimiya-kokomi/Miao-Yunzai>，本机版本 `ac73baa0ca079d7fcacc158a9746774de497a102`。
- `characters.json`：从本机 Miao-Plugin 的 `resources/meta-sr/character/data.json` 提取角色 ID 和中文名称，用于补齐米游社挑战接口未返回的名称。
- Miao-Plugin 源码：<https://github.com/yoimiya-kokomi/miao-plugin>。
- 预览角色头像：米游社真实挑战 API 返回的官方头像 URL；未制作 AI 替代图。
