# B 站解析与下载

返回：[项目主页](../README.md) / [文档目录](README.md)

## 功能特性

- 支持 B站长链接、短链接、BV 号、av 号和 QQ 分享卡片。
- 视频解析会输出图片卡片，并继续走 TuneWeave + JS 下载后发送视频文件。
- 直播只发送信息卡和独立播放器链接，不做直播下载。
- 每次下载使用独立任务目录，不复用下载文件；同一视频在多个群同时或前后脚触发时分别处理。
- 同一机器人发送相同文件内容时，上传按顺序执行，上一份返回后立即发送下一份；不同内容和不同机器人仍可并发。此保护覆盖 B站和抖音共用的媒体发送层，保留原标题及显示文件名，避免 QQ 内部按内容映射的缓存被并发复制覆盖。
- 等待发送完成后清理本任务目录，下载或发送失败也只清理本任务。
- TuneWeave + JS 单 P、多 P 产物使用 BV、分 P 序号和 CID 命名，标题中的符号或超长文字不参与物理路径生成；发送时保留视频标题或分 P 标题作为显示文件名。
- 视频、图片和附件共用传输路径处理，特殊名称通过独立临时别名发送，避免裸 `%`、`%20`、引号等被适配器当作 URL 解码。别名在发送完成或失败后清理，原文件保留至任务清理。
- ZIP 标题按 UTF-8 字节和完整字素限制长度，并处理控制字符、尾随点/空格及 Windows 保留名称。

## 指令用法

```text
<B站链接或编号>
#搜视频 <关键词>
#荷花搜视频 <关键词>
#看<序号>
#看视频 <关键词>
#荷花看视频 <关键词>
#B站下载 <BV号或链接>
#荷花下载 <BV号或链接>
#B站登录
#初始化环境
```

## 变量说明

- `B站链接或编号`：必填，支持长链、短链、BV 号、av 号和 QQ 分享卡片。
- `关键词`：必填，视频搜索关键词。
- `序号`：必填，搜索结果序号。
- `BV号或链接`：必填，要播放或下载的视频编号或链接。

## 补充说明

解析卡片包含封面、主标题、简介、UP主、视频时长和互动数据。

B站搜索、详情及播放清单使用 TuneWeave，下载由 JS 完成，FFmpeg 合流。默认并发 4，可在锅巴或插件面板调整；分P策略继续支持 first/all/zip。每个请求使用独立目录，完成或失败后清理本任务。

登录推荐发送 `#B站登录`。二维码由 TuneWeave 创建和保存，Lotus 仅保存账号引用。历史 Cookie 数据不会自动删除；旧 Cookie 无法由当前 TuneWeave 导入时，需重新扫码建立账号引用。

建议使用 [TuneWeave 1.0.0-beta.2](https://github.com/MOPELotus/TuneWeave/releases/tag/v1.0.0-beta.2) 或更新版本。beta.2 已取消播放清单中的 CDN 域名、端口与路径白名单，兼容 B站返回的新备用地址，无需额外实验补丁。
