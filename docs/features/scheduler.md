# 签到调度-随机与固定

返回：[上一级](../checkin.md) / [文档目录](../README.md) / [小功能索引](README.md)

## 功能特性

- 固定模式使用全局签到时间。
- 随机模式会在前一天生成次日计划，并把用户平均分布在 `00:00-23:30`。
- 已生成的计划会在重启后继续使用，不会重复洗牌。
- 锅巴面板和配置文件使用七段 cron。

## 指令用法

```text
#生成签到计划
#我的签到时间
#执行到期签到
#签到随机模式
#签到固定模式 <时间>
#签到计划生成 <时间>
#签到名单列表
#自动签到日志
#批量刷新签到

#随机签到时间[profile]
#固定签到时间[profile] <时间>
#跟随全局签到时间[profile]
```

## 变量说明

- `profile`：可选，Lotus 内部 profile 序号，范围 `1..255`；省略时使用 profile 1。
- `时间`：必填，使用 `HH:mm`，例如 `04:30`。

到期扫描会自动补建缺失的当天计划，并按当前配置同步未完成的固定时间任务；原有随机时间保持稳定，已完成或正在执行的条目不会重建。继承全局模式时使用全局固定时间，只有主人明确设置的 profile 固定模式才使用其独立时间。普通用户不能通过网页或聊天指令修改模式与时间，个人网页仅显示今日安排。

自动签到时，国服游戏角色查询遇到 HTTP 410、403、服务端错误或网络超时，会分别等待 5 秒和 15 秒重试。社区任务状态查询也会对临时错误短重试。遇到 HTTP 429 时直接等下一轮补跑。

当天仍待处理的游戏和社区分区会保存在签到计划中，依次等待 10 分钟、1 小时、3 小时，之后每隔 6 小时再试。23:50 执行当天最后一次补跑，首轮结束较晚时还会在 23:59 检查一次。游戏补跑先重新查询角色和今日签到状态，仅为尚未签到的角色提交。其他游戏和阅读、点赞、分享任务沿用首轮结果。
