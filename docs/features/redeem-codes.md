# 前瞻兑换码

Lotus 接管原神、星穹铁道、绝区零、崩坏三的前瞻兑换码查询。不需要登录或 Cookie，不执行兑换。

| 游戏 | 常用指令 |
| --- | --- |
| 原神 | `#兑换码`、`#原神兑换码` |
| 星穹铁道 | `*兑换码`、`#星铁兑换码`、`#崩铁兑换码` |
| 绝区零 | `%兑换码`、`#绝区零兑换码`、`#zzzcode` |
| 崩坏三 | `#崩三兑换码`、`#崩坏三兑换码`、`#崩坏3兑换码` |

也支持“前瞻兑换码”“直播兑换码”。有可用兑换码时发送合并转发，保持原文内容和顺序，将标题、各条兑换码、对应奖励、有效期、来源分别拆成独立消息。每条兑换码消息只包含兑换码，直接复制该条即可使用。中文兑换码同样保留，包含当前已发布的全部条目。过期、尚未发放和查询失败时直接发送文字提示。

## 来源与更新

每次查询都重新发现活动、读取活动版本和兑换码版本，不固定 `act_id` 或 `code_ver`，也不缓存兑换码。相同游戏的并发查询共享本次请求，结束后的下一次查询会重新获取。官方尚未公开的兑换码无法提前取得。

请求沿用机器人网络设置。连接或响应读取失败、服务器暂时错误时，对相同官方接口直连重试，最多三次，单个接口总耗时不超过约 20 秒；仅作用于本功能的官方域名，不修改全局代理。原请求与重试均失败时会报错，并记录失败的接口和网络错误码。

活动从米游社首页导航、官方账号帖子、帖子全文发现；必要时使用社区搜索，但只接受对应官方账号的结果。活动详情还会校验官方主播账号，避免把转载或其他游戏的活动当成官方来源。

发现更高版本预告后，停止展示上一版本的码，等待新版本官方活动与兑换码。活动尚未开始、暂未发码、已经过期和接口失败会分别说明；接口失败不拿历史兑换码充当最新结果。

有效期优先读取官方前瞻页面的兑换码说明，其次读取同版本官方帖子中明确写出的失效时间。统一显示北京时间，不按发帖日期或 `to_get_time`（发码时间）加天数推测。官方未明确公布失效时间时会说明。旧活动页面撤下后，仍可依据同版本官方回顾帖说明已过期。

已发现的活动 ID 保存在本插件 `data/redeemCodes/activities.json`，用于导航撤下后的重新发现，重启仍可读取；该记录不包含兑换码、账号或凭据。首次安装遇到已撤下且无可发现链接的活动，可能只能确认过期，或提示尚未找到官方页面。

## 替代上游入口

复用 Lotus 的冲突禁用写入机制，将 genshin 应用 `兑换码` 与绝区零应用 `[ZZZ-Plugin]Code` 写入 Yunzai `group.yaml` 的 `default.disable`，并在运行时合并禁用项。无需修改上游源码，不影响这些插件的其他应用。

genshin 将“兑换码使用 / cdk-u”与查询放在同一个应用里，因此这两个旧入口也会停用。

## 后续接入游戏

游戏定义集中在 `services/redeemCodes/games.js`，包含指令别名、前缀、社区 ID、官方账号和数据提供器。使用相同官方直播接口的游戏补充定义即可；使用其他接口时可新增提供器，统一发现活动和读取兑换码，不需要重新实现指令、并发请求和历史记录。

星布谷地、崩坏因缘精灵、雨之城、源初之结等尚未接入；待官方社区与兑换码来源明确后补充，不预设社区 ID 或账号。
