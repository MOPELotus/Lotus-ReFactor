# 米游社功能与插件面板

返回：[项目主页](../README.md) / [文档目录](README.md)

私聊机器人发送 `#米游社功能`，获取个人总页链接。`#米游币兑换`、`#米游币商城` 和 `#荷花面板` 打开同一网页；链接限时、仅能使用一次，请勿转发。

总页按当前登录用户的 profile 展示账号与设备状态、当前社区任务、签到设置、米游币余额、商品、持续追踪和兑换记录。切换 profile 后管理对应账号，不能通过提交别人的 QQ 操作其他用户数据。现有聊天管理指令继续有效，与网页保存到同一份配置。

## 签到、任务和兑换

- 国内游戏、HoYoLAB 和云游戏按各自开关与凭证执行；单项失败不影响其他游戏。
- 游戏签到在提交后回读状态，区分本次签到、已经签到、跳过和失败。
- 社区任务以官方给当前账号返回的任务为准。没有阅读、点赞、分享任务时不执行这些旧动作；绑定游戏角色、完善签名等任务展示实际状态，需要在米游社完成的操作不会自动代填。
- 米游币按执行前后任务状态回读，不把接口请求成功等同于奖励到账。游戏奖励和云游戏时长单独记录。
- 网页支持保存个人开关、分区、签到时间及通知设置，也可以手动启动任务并查看执行记录。
- 已有兑换商品、预约、持续追踪和目标校验继续使用；签到与兑换共用账号执行互斥。兑换结果不确定时保留待确认，不自动重发消费请求。

国内协议版本与配套 salt 集中在 `core/mihoyo/constants.js`。BBS、Passport 和 HoYoLAB 按协议分别管理，设备上报优先保留提供的真实版本；升级不会改写既有设备 ID、指纹或凭证。

## 主人配置

普通用户只看到个人管理。机器人主人可进入“主人配置”，按折叠分类修改插件全局设置；锅巴使用同一份字段定义、读写与校验。密码框留空保留原值，明确勾选清除才会删除已有密钥。

复杂的个人任务与兑换交互放在插件面板，锅巴继续承担主人配置。启动项修改后需重启机器人，其他设置按对应功能的热加载能力生效。网页沿用已有端口、挂载路径和部署方式，不要求更换反向代理地址。
