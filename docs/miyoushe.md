# 米游社功能与插件面板

返回：[项目主页](../README.md) / [文档目录](README.md)

私聊机器人发送 `#米游社功能`，获取个人总页链接。`#米游币兑换`、`#米游币商城` 和 `#荷花面板` 打开同一网页；链接限时、仅能使用一次，请勿转发。

总页按当前登录用户的 profile 展示账号与设备状态、当前社区任务、签到设置、米游币余额、商品、持续追踪和兑换记录。切换 profile 后管理对应账号，不能通过提交别人的 QQ 操作其他用户数据。现有聊天管理指令继续有效，与网页保存到同一份配置。

## 签到、任务和兑换

- 国内游戏、HoYoLAB 和云游戏按各自开关与凭证执行；单项失败不影响其他游戏。
- 游戏签到在提交后回读状态，区分本次签到、已经签到、跳过和失败。
- 社区任务以官方给当前账号返回的任务为准。没有阅读、点赞、分享任务时不执行这些旧动作；绑定游戏角色、完善签名等任务展示实际状态，需要在米游社完成的操作不会自动代填。
- 米游币按执行前后任务状态回读，不把接口请求成功等同于奖励到账。游戏奖励和云游戏时长单独记录。
- 网页支持保存个人开关、分区及通知设置，也可以手动启动任务并查看验证码进度。账号状态区只读显示今日签到安排与执行状态，不提供时间修改或最近执行列表；签到模式与时间由主人统一管理。
- 已有兑换商品、预约、持续追踪和目标校验继续使用；签到与兑换共用账号执行互斥。兑换结果不确定时保留待确认，不自动重发消费请求。

国内协议版本与配套 salt 集中在 `core/mihoyo/constants.js`。BBS、Passport 和 HoYoLAB 按协议分别管理，设备上报优先保留提供的真实版本；升级不会改写既有设备 ID、指纹或凭证。

## 主人配置

主人私聊发送 `#荷花管理面板`（兼容 `#荷花配置`），获取独立管理页面的限时链接。管理页使用分类侧栏，按单插件组织设置；用户总页不再提供主人配置入口。锅巴与独立管理面板共用同一份字段定义、读写与校验。密码框留空保留原值，明确勾选清除才会删除已有密钥。每次只保存当前分类中实际修改的字段。

管理链接仅主人可申请，默认 10 分钟内有效且只能使用一次。主人可在“网页登录”分类分别设置用户登录链接与管理链接的有效期（正整数分钟），对应 `coin_shop.ticket_minutes` 和 `coin_shop.panel_ticket_minutes`。新签发链接立即采用新设置，已有链接保留签发时的期限。

一次性链接用于登录，登录后由浏览器 Cookie 保存独立的限时令牌。用户令牌默认 8 小时，管理令牌默认 24 小时，可通过 `coin_shop.session_hours` 与 `coin_shop.panel_session_hours` 分别设置正数小时，支持小数；新登录采用新设置。令牌在原有效期内跨机器人重启保留，无需重新获取链接；退出会撤销当前令牌，过期后需重新申请登录链接。服务端仅持久化令牌哈希及必要会话信息。

用户页面和管理页面使用不同用途的登录链接及浏览器令牌，不能互相兑换或借用；管理页面每次访问接口都会重新核对当前主人资格，配置写入另校验 CSRF 凭据，失去主人资格的令牌无法继续管理。不要转发登录链接，也不要分享浏览器 Cookie。

默认管理路径为 `/lotus/panel/`，用户页仍是 `/lotus/coin-shop/`，共用现有端口。使用反向代理时需同时转发两个路径。启动项修改后需重启机器人；签到模式和固定时间会在下次到期扫描时同步未完成计划，已完成或正在执行的条目保留，避免重复签到。
