# 代操作与批量执行

返回：[项目主页](../README.md) / [文档目录](README.md)

仅机器人主人可以发起：

```text
#代 @用户 #体力2
#代 123456789 #体力2
#执行 @用户 #体力
#执行 全员 #体力
#执行 123456789,987654321 群=12345678 间隔=5 静默=关 -- #体力2
#执行 全员 群=全部群 间隔=5 静默=开 -- #体力
#执行 123456789 群=私聊 -- #体力
```

默认使用当前会话，批量间隔五秒，回复发到目标会话。支持当前群、指定群、全部群及明确用户私聊；私聊不支持“全员”。静默会拦截插件通过事件 reply 发出的回复，不宣称能拦截第三方插件绕过事件直接发送的消息。

目标事件重新构造用户、消息段、群聊或私聊、机器人与运行上下文；目标权限由 Yunzai 重新判定，Lotus 按目标用户及指令后缀选择 profile。不能嵌套执行代操作。

旧 `#execute in:here as:123456789 gap:5 hold:false run:#体力2` 仍可使用，包括 `in:@s` 私聊、`in:@e` 全部群及 `as:@a` 全员。新入口不再要求记忆这套语法。

执行汇总区分已处理、异常和未命中或被拒绝；已处理不代表业务接口一定成功，以各指令实际结果为准。
